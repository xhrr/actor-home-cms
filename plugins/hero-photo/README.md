# hero-photo — 首页粒子 hero

首页首屏的暗色/明色调改版插件。它接手 `.hero` 之后做的事：站点照片和原有的 hero 文案（名字、英文名、定位语）都原样保留，叠一层调性遮罩保证文字可读，再加一整面粒子场——满场浮尘、沿弧线流动的粒子带、星芒、虚化光斑，桌面端还有跟随鼠标的景深视差。

点击 hero 的空白处，全部粒子会飞过去聚成一个形状，跳一次心跳，然后就地散开回到漂浮状态。聚什么形状在后台选。

## 后台配置

面板在「插件管理 → 首页粒子 hero」，三件事：

- **启用聚形特效**：关掉后点击不再触发动画，排版和粒子场还在；彻底不要这个插件就在插件列表停用
- **点击汇聚形状**：月牙（默认）/ 心形 / 五角星 / 皇冠 / 花开，也可以选「每次随机」
- **明暗调**：明调是底部一条米白渐变（只盖文字区，照片保持通透）配墨色文字和金粉发光珠；暗调是整幅压暗的电影感，暖白星尘

配置存在 `SITE_CONFIG.plugins.data['hero-photo']` = `{ enabled, shape, tone }`，改完刷新首页生效。

## 实现上值得知道的几件事

- **所有形状槽位都是「数学坐标算完再翻转 y」**。经典心形、月牙这些公式都默认 y 轴向上，而画布 y 轴向下——第一版心形上下颠倒了就是这个没翻转。新加形状时先想清楚坐标系
- **窄屏（宽 < 768px）有独立的一套缩放**：形状放大约 1.7 倍、粒子密度 ×1.5，都走 `sc(桌面值, 窄屏值)` 这一个口子。曾经竖屏下月牙只有 86px 还被星芒砸得变形，就是缺这层适配
- **聚形期间星芒会自动抑制**（flareMin 从 0.85 抬到 1.0），不然几个大十字闪过会把细的轮廓砸乱
- 粒子颜色分两条渲染路径：明调用预渲染的辉光 sprite 贴图（浅底上平面圆点看不见），暗调用加色混合的圆点。改配色注意两边是分开的
- 插件只在存在经典 `.hero` 的页面生效；首页若切成 hero-split 模式，本插件会静默不动

## 部署与配置可见性

- 插件目录是挂载卷：`cp` 到 `/vol1/1000/actor/mqq/plugins/` 后 `docker restart actor-home-cms` 即可，不用重建镜像
- 配置要被前端读到，插件名必须在 `lib/core.js` 的 `EXPORTABLE_PLUGIN_DATA` 白名单里（已加）。改了 lib 就要重建镜像
- 公共站（Cloudflare Pages）要生效，需要走一次导出加推送
